// PRIORITY ISSUES
P0

Homepage Title Duplicates the Brand

Rendered title is "Softcredible - We Build Software That Moves Businesses Forward | Softcredible". The homepage passes the full brand name as its title and useSeo appends "| Softcredible".

FIX: Pass a title without the brand suffix on the homepage, or special-case it in useSeo.
P1

Card Density Flattens Hierarchy

29 card instances and 44 H3s on the homepage. Problems, solutions, outcomes, and values all render as identical rounded-xl shadow-sm boxes, so nothing expresses priority.

FIX: relayout - demote secondary sections to flat type with dividers; reserve cards for genuinely discrete content.
P1

No Distinctive Color or Type Voice

Navy + signal blue and Inter alone are the default software-industry register. The accent and primary are near-family, so there is no mood tension or emotional arc.

FIX: recolor to a hue with a reason; typeset to add a secondary face or typographic gesture.
P2

Generic Hero Proof Object

The homepage hero pairs the H1 with a decorative ArchitectureVisualization SVG that could illustrate any software company's pitch.

FIX: voice/redesign - replace with a Softcredible-specific artifact or concrete portfolio evidence.
P2

Small Touch Targets on Admin Inline Actions

Admin table text actions (Assign, Edit, Delete) and inline status selects fall below the 44px comfortable touch target.

FIX: interaction - expand hit areas with larger controls or pseudo-element padding.
